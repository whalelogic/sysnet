# Foundations

This directory establishes the initial hierarchy for `sysnet` learning and operations material.

## Concepts

- `network-scanning/` - host discovery and port/service visibility scripts.
- `active-directory/` - baseline domain inventory and AD operations scripts.
- `sql-server/` - starter SQL Server checks and diagnostics.
- `ip-mac-configuration/` - IP and MAC inspection scripts for Linux and Windows.
- `tooling/` - setup helpers for terminal utilities like nmap and netcat.
